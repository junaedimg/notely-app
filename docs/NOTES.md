# Notes

Notes are used to store information.

## Examples

- Learning notes
- Daily knowledge
- Documentation
- Vehicle maintenance records
- Personal ideas

## Characteristics

A Note is **passive**. It never contains scheduling logic.

A Note does **not** know about:

- Reminder
- Deadline
- Repeat
- Priority
- Task status

Notes simply answer one question:

> **What do I know?**

## Responsibilities

**Responsible for:**

- Knowledge
- Documentation
- Ideas
- Learning notes

**Not responsible for:**

- Reminder
- Schedule
- Repeat
- Priority
- Progress
- Deadline
