# Personal Notes & Todo

> A lightweight personal productivity application focused on **knowledge management** and **task management**.

---

## Philosophy

> **Separate Knowledge from Action.**

Knowledge and Action solve different problems and should never be mixed.

```
Knowledge  → Notes
Action     → Todos
History    → Todo Histories
```

---

## Core Modules

| Module        | Purpose                   |
|---------------|---------------------------|
| Notes         | Store knowledge           |
| Todos         | Represent actions         |
| Todo History  | Track execution           |

Notes preserve knowledge. Todos drive action. History records reality.

---

## Design Principles

- **Single Responsibility** — Each module has one concern.
- **Data Normalized** — No duplication; rules vs execution vs calculation.
- **Simple First** — Avoid unnecessary complexity.
- **Extensible** — Add modules without changing existing ones.
